# LIP-0001: Link Improvement Proposals

- **Status:** Draft
- **Created:** 2026-11-08
- **Affects:** process for this repository

## Summary

Design proposals for Swarma Link live in `lips/` as numbered LIPs. Each
records the problem, evidence, alternatives, recommendation and open
questions. A LIP is not normative. Adoption happens through a decision record
in `decisions/` plus the corresponding change to `protocol/` and
`conformance/`.

## Statuses

`Draft` → `Proposed` → `Accepted` or `Rejected`; an accepted LIP becomes
`Final` when its decision record and normative text are released. `Withdrawn`
is allowed at any point before `Final`.

## Template

Summary · Motivation · Current state · Proposal · Alternatives · Security
consequences · Conformance impact · Open questions.
